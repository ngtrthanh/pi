# Benchmarks

Benchmarks in this folder test whether architectural ideas produce measurable value.

Rules:

1. freeze the task spec before comparing variants;
2. use clean workspaces;
3. record actual physical models;
4. keep quality and efficiency metrics separate;
5. do not promote an architectural claim from one run;
6. record critical defects separately from aggregate scores;
7. prefer at least three repetitions before a strong conclusion.
