# Product positioning

## Do not position as

- another personal AI assistant
- a better OpenClaw clone
- a better Hermes clone
- a Claude Code clone
- a Codex clone
- a generic workflow engine

## Working positioning

> A minimal durable agent runtime with risk-governed continuous improvement.

Alternative:

> Govern autonomous work under limited resources and continuously raise an evidence-backed baseline.

## Competitive shorthand

These are positioning mnemonics, not factual product claims:

```text
OpenClaw     → Connect everything
Hermes       → Remember and learn
Claude Code  → Engineer software
Codex        → Command software agents
Cowork       → Delegate knowledge work
ChatGPT Work → Complete general work
Pi new       → Govern autonomous improvement
```

## Potential category

**Governed agent runtime**

The key differentiation is not more features.

It is the control philosophy:

```text
objective
   ↓
risk assessment
   ↓
resource allocation
   ↓
durable execution
   ↓
evidence
   ↓
standardized baseline
   ↓
next spiral
```

## Enterprise relevance

The same loop can govern:

- coding
- infrastructure
- production operations
- maintenance
- research
- data quality
- compliance work
- business process improvement

The domain data stays in the domain SST.

Pi manages work against that truth.

## Core promise to test

> Every completed spiral should leave measurable evidence that the system is better, safer, more capable, or has consciously accepted its residual risk.

This is the hypothesis.

It requires benchmark evidence before becoming a product claim.
