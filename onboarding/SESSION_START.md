# Session start template

Use this when starting substantial work with Pi.

```text
Objective:
<desired user-visible result>

Repository / workspace:
<path or repo>

Current baseline:
<known-good commit/state>

Constraints:
<time, budget, environment, compatibility, things not to change>

Acceptance:
<tests / runtime behavior / artifacts that must pass>

Working mode:
- inspect first
- record material risks
- keep scope bounded
- use objective evidence
- defer acceptable residual risk
- standardize the new baseline
- hand off clearly if unfinished
```

For trivial work, do not force a full PDCA cycle.
